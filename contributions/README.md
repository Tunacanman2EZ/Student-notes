# Contributions: shared lesson notes

This folder is where students' share files arrive. Anyone can read them, because this repository is public.

## How to share
1. In the app, open **Share**, pick a class, tick lessons, and click **Download share file**.
2. Upload the file here: **Add file → Upload files** (GitHub makes a pull request for you).
3. A safety check runs automatically. After a review, your notes join the library.

## The rules (checked automatically, by the same code the app uses)
- **Reviews, finals, quizzes and exams are never shared.** School rules.
- **No emails or phone numbers.** The app replaces them with [hidden]; the check rejects any that are left.
- Only a display name and a random id identify who shared. No real names or emails.
- A pull request may only add share files to this folder, nothing else.
- Files must be made by the app (or match its format), under 2 MB.

Please only share **your own** notes.
